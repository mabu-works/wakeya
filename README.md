# わけや｜グループ分けツール

参加者全員をランダムにグループ分けする静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

🌐 公開先: [wakeya.vercel.app](https://wakeya.vercel.app)

## ✨ 機能

- 参加者リストを1行1人で入力するテキストエリア（貼り付け対応）
  - 空行は無視されます
  - 同名でも別々の人として扱います（名簿の同姓同名対応。重複行は統合しません）
  - 参加者数をリアルタイム表示します
  - リストのクリア／サンプル入力ボタンつき
  - 入力と分け方の設定はブラウザに自動保存され、再訪時に復元されます（「リストをクリア」で保存も消去されます）
- 分け方の指定は2通り
  - **グループ数で指定**：何グループに分けるかを指定
  - **1グループの人数で指定**：1グループあたりの人数を指定（グループ数は自動計算）
- 均等なグループ分け：シャッフル後に配るため、どのグループも人数の差は最大で1人まで
- シャッフル演出：短いアニメーションのあとに結果を表示
- 結果表示：グループごとにカード表示（グループ名・人数・メンバー一覧）
- 「再シャッフル」ボタン：同じ設定でもう一度分け直し
- 結果のコピーボタン（グループ分け結果をテキストでクリップボードへ）
- 結果の印刷ボタン（印刷時は入力UIを隠し、グループ表だけを紙面に出します）
- 設定が不正なときは日本語のメッセージで知らせます（参加者不足、グループ数が参加者数より多い、1グループの人数が参加者数を超える、など）
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダークモード対応（prefers-color-scheme）

## 📝 使い方

1. 参加者を1行に1人ずつ入力します（名簿などをそのまま貼り付けてもOKです）。
2. 分け方を選びます。「グループ数で指定」ならグループ数を、「1グループの人数で指定」なら1グループあたりの人数を入力します。
3. 「グループ分けする」を押します。シャッフル演出のあと、全員のグループ分け結果が表示されます。
4. 分け直したいときは「再シャッフル」、共有したいときは「結果をコピー」、紙に残したいときは「結果を印刷」を押します。
5. 入力した名簿と分け方の設定は自動で保存されるため、ページを閉じても次回そのまま続きから使えます。名簿を消したいときは「リストをクリア」を押してください（保存も一緒に消えます）。

## くじやとの違い

- **くじや**は、参加者リストから**当選者を選ぶ「抽選」**向けです。一部の人だけを選びたいときに使います。
- **わけや**は、**参加者全員をグループに分ける**ためのツールです。チーム分けや班分けのように、全員を漏れなく分けたいときに使います。選ばれない人は出ません。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。分け方（グループ数／1グループの人数の2方式、人数差が最大1になる均等分け）とシャッフル演出（1200ms）は Web 版と同じで、オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Wakeya.exe` を生成

## 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- グループ分けは Fisher-Yates シャッフル後に先頭から順に配る方式で、各グループの人数差は最大で1人です。
- 「1グループの人数で指定」の場合、グループ数は `ceil(参加者数 ÷ 1グループの人数)` で求め、同じく人数差が最大で1人になるよう配ります（そのため、最後のグループだけ極端に少なくなることはありません）。
- シャッフル演出は約1.2秒間、50ミリ秒間隔で参加者の名前をランダムに切り替えて表示します。
- 入力内容はブラウザ内でのみ処理され、サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: wakeya-v3）。
